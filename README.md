# Abripanes

[![ContentDB](https://content.luanti.org/packages/mt-mods/abripanes/shields/downloads/)](https://content.luanti.org/packages/mt-mods/abripanes/)
[![Translation status](https://translate.luanti.ch/widget/mt-mods/abripanes/svg-badge.svg?capitalize=1)](https://translate.luanti.ch/engage/mt-mods/)
[![luacheck](https://github.com/mt-mods/abripanes/actions/workflows/luacheck.yml/badge.svg)](https://github.com/mt-mods/abripanes/actions/workflows/luacheck.yml)

Mod for Luanti/Minetest which adds faintly glowing coloured glass panes.
These can be used for stained glass windows or for gentle lighting.

## Crafting

Coloured glass panes can be made from six glass nodes and the matching dye.

## Dependencies

- Luanti/Minetest v5.10
- MTG mods `default` and `dyes`
